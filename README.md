# alphaclinicvital

Aplicação web institucional de alto padrão para a **Alpha Clinic Vital**, clínica de estética médica avançada e bem-estar no Centro Comercial AlphaCenter, Jardim Botânico, Brasília - DF.

## Tecnologias
- React 19 / Vite
- TypeScript
- Tailwind CSS
- Motion (Framer Motion v12)
- Lucide React

## Execução Local
```bash
npm install
npm run dev
```

## Build de Produção
```bash
npm run build
```
